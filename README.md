# Сайт в разработке (Coming Soon)

Простая и красивая страница-заглушка «Скоро открытие» для сайта, который находится в стадии разработки.

## Описание

Страница сообщает посетителям, что сайт ещё в работе и скоро будет готов.  
Используется современный дизайн с градиентным фоном, эффектом стекла (glassmorphism) и анимированным индикатором загрузки.

## Возможности

- Адаптивный дизайн (хорошо выглядит на мобильных и десктопах)
- Красивый градиентный фон
- Полупрозрачный контейнер с размытием
- Анимированный спиннер загрузки
- Поддержка favicon
- Чистый HTML + CSS (без внешних зависимостей)

## Структура проекта

```
website-loading-page
├── README.md
├── favicon.ico
└── index.html
```

## Как запустить

Просто откройте файл `index.html` в любом современном браузере.

## Настройка

Вы можете легко изменить текст, цвета и стили прямо в `index.html`:

- **Заголовок** — тег `<h1>`
- **Описание** — тег `<p>`
- **Цвета градиента** — свойство `background` у `body`
- **Скорость анимации** — значение в `@keyframes spin`
